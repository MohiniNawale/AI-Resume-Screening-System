# 🤖 AI Resume Screening System(Mini-Project)

# 📌 Project Overview

The AI Resume Screening System helps automate the resume screening process by extracting text from resume PDFs and comparing it with a job description.

The system calculates:
- 📊 Resume Match Score
- 🛠 Technical Skills
- ✅ Resume Acceptance/Rejection

This project reduces manual work and improves hiring efficiency.

---

# ❗ Problem Statement

Companies receive thousands of resumes for job applications.

Manual resume screening:
- ⏳ Takes a lot of time
- ❌ Can lead to human errors
- 📄 Makes recruitment difficult

There is a need for an automated AI-based solution for resume analysis.

---

# 💡 Proposed Solution

This project provides an intelligent Resume Screening System using:
-  Machine Learning
-  NLP Techniques
-  PDF Text Extraction
-  Dashboard Visualization

The system:

1️⃣ Uploads Resume PDF  
2️⃣ Extracts Resume Text  
3️⃣ Takes Job Description Input  
4️⃣ Calculates Resume Match Score  
5️⃣ Extracts Technical Skills  
6️⃣ Accepts or Rejects Resume  
7️⃣ Displays Dashboard Charts  

---

# 🧠 Machine Learning Model

## 🔹 TF-IDF Vectorizer

Converts text into numerical vectors for comparison.

## 🔹 Cosine Similarity

Measures similarity between:
- 📄 Resume
- 📋 Job Description

Higher similarity = Higher Resume Score ✅

---

# 🔄 Project Workflow

Resume Upload -> PDF Text Extraction -> Job Description Input -> Text Processing -> TF-IDF Vectorization -> Cosine Similarity -> Resume Match Score -> Skill Extraction -> Accept / Reject Decision -> Dashboard Visualization
